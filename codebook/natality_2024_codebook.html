US Natality File Codebook, Data Year 2024

Every field in the NCHS natality public-use file (the birth certificate microdata behind CDC natality statistics), with its tape position, width, and every code and category the User Guide defines.

Record: fixed format, 1,330 characters per birth. 3,638,436 US births and 22,662 territory births in 2024. Positions below are character columns in that record.

Reporting flags (F_ fields) mark whether the record comes from an area that reports that item. In the User Guide's words, data from non-reporting areas are represented by blanks ("not on certificate").

Codes shown as a range (for example 00-97) stand for every value in that range. Rows in shaded italics are sub-headings inside one variable (for example, the Puerto Rico version of marital status).

Source. National Center for Health Statistics. User Guide to the 2024 Natality Public Use File. Hyattsville, MD: NCHS. File layout and addendum. ftp.cdc.gov/.../UserGuide2024.pdf

Filler positions are omitted. Variable names, descriptions and codes are taken from the User Guide text; spelling follows the source (for example, race labels such as "White (only)" are NCHS code labels). Positions and codes apply to the 2024 file; check each year's User Guide before reading another year's file.
